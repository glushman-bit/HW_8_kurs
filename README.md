## Проект платформы для онлайн обучения. 
### Ветка 30.1

 - Инициализирован проект Django. Подключен DRF.
 - Созданы приложения Users и Materials, зарегистрировано, настроена маршрутизация.
 - Созданы модели для курса и урока, для реализации CRUD для курса использован Viewsets, а для урока - Generic-классы..
 - Для работы контроллеров описаны простейшие сериализаторы.
 - Работу каждого эндпоинта проверена с помощью Postman.

### Ветка 30.2
 - Для модели курса добавлено в сериализатор поле вывода количества уроков. Поле реализовано с помощью SerializerMethodField().
 - Добавьте Платежи модель в приложение users.
 - Создана кастомная команда для добавления данных для модели платежи.
 - Для сериализатора для модели курса реализовано поле вывода уроков. Вывод с помощью сериализатора для связанной модели.
 - Настроена фильтрация для эндпоинта вывода списка платежей с возможностями:
 
 менять порядок сортировки по дате оплаты:
```
http://localhost:8000/users/payments?ordering=-date_payment
```
 фильтровать/искать по названию курса или названию урока:
```
http://localhost:8000/users/payments?search=Математика
```
 фильтровать по способу оплаты:
```
http://localhost:8000/users/payments?payment_method=transfer
```
 - Для профиля пользователя реализован вывод истории платежей, расширив сериализатор для вывода списка платежей.

### Ветка 31
 - Реализован CRUD для пользователей, в том числе регистрация пользователей.
 - Создана группа модераторов, для нее описаны права работы с любыми уроками и курсами, но без возможности их удалять и создавать новые. 
 - Для группы модераторов создана фикстура и кастомную команду для заполнения созданной группы в базе данных.

 Для предварительного заполнения БД используйте фикстуры
```
python manage.py loaddata users_fixture.json
```
 или кастомную команду
```
python manage.py create_group_moderators 
```

 - Добавлены права доступа просмотра, редактирования и удаления своих курсов и уроков для пользователей - владельцев.
 - Добавлены ограничения для пользователя: пользователь может просматривать все профили, но видит только общую информацию. Редактировать может только свой профиль.
